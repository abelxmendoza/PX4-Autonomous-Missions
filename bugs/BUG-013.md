BUG-013

Scenario:
Live SITL flight (`waypoints` mode) exercising an aggressive avoidance
sidestep near the west fence edge.

Requirement violated:
REQ-GEOFENCE-01 (hard geofence breach shall trigger FAILSAFE) — the
geofence correctly caught the breach and triggered FAILSAFE as
designed, but the breach itself should never have happened given the
configured soft geocage margin.

Symptom:
A real SITL run recorded a hard geofence breach at `east = -23.4`m
against a fence boundary of `east_min = -23.0`m, despite a configured
1.0m geocage margin that should have clamped any commanded setpoint to
no closer than `east = -22.0`m.

Expected behavior:
The soft geo-cage should keep the vehicle's actual tracked position
comfortably inside the hard geofence boundary, with enough margin to
absorb normal PX4 position-tracking error during an avoidance maneuver.

Actual behavior:
The vehicle's real tracked position overshot the clamped setpoint by
roughly 1.4m during an aggressive avoidance sidestep — more overshoot
than the 1.0m margin could absorb — and crossed the hard fence boundary
before the geofence failsafe could act.

Root cause:
Not a clamping-logic bug (`_apply_geocage` was confirmed to run
correctly, immediately after `_apply_avoidance`, every control tick).
It was a value bug: a 1.0m margin was simply too tight for PX4's real
position-tracking overshoot during an aggressive maneuver in this
avoidance mode. The soft cage and the hard fence were close enough
together that normal, expected tracking error alone could close the
gap.

Fix:
Increased `geocage_margin_m` from 1.0 to 3.0 in
`config/offboard_mission.yaml`, `src/px4_offboard/config/offboard_mission.yaml`,
and the code-level default in `offboard_mission.py`, with an inline
comment recording the specific overshoot measurement that motivated the
new value.

Regression test added:
None — this is a numeric-tuning fix to a configuration constant, not a
logic change; there is no code path for a unit test to exercise
differently. Verified by a live SITL re-run through the same
avoidance maneuver showing no further geofence breach at that location.
