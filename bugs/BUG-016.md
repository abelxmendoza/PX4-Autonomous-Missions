BUG-016 (OPEN — not yet fixed)

Scenario:
Live SITL flight (`waypoints` mode) verifying the BUG-015 fix, exiting
the GPS-denied zone during active avoidance.

Requirement violated:
REQ-GEOFENCE-01 (breach correctly triggered FAILSAFE), but the breach
itself indicates a separate, unresolved problem in the GPS-denied
zone-exit / localization-source-switch path — not the avoidance logic
BUG-013/014/015 addressed.

Symptom:
Altitude jumped from roughly 2-3m to 11.6m within about 3 seconds,
immediately followed by a `LOC | GPS_RESTORED source=GPS in_zone=0
inject=0` log line, a geofence breach at 12.4m (against a 12.0m
ceiling), and a FAILSAFE landing. The mission had otherwise made real
progress (waypoint 6 of 9, versus permanently stuck at waypoint 3 before
BUG-015's fix) — this is a different failure from the one being
verified, not a recurrence of it.

Expected behavior:
Not yet established — needs investigation into whether the
localization-source switch at zone exit should produce any altitude
change at all, and if the observed altitude is a real, physically
commanded climb or an EKF/position-estimate artifact of the source
switch.

Actual behavior:
An altitude excursion coincident with GPS restoration, well beyond any
change the mission logic should be commanding during ordinary
avoidance, large enough to breach the fence's altitude ceiling.

Root cause:
Not yet determined. Candidate hypotheses, none yet confirmed:
(a) a genuine PX4 EKF2 position/altitude estimate discontinuity when
localization source switches back to GPS; (b) a bug in how the mission
code handles the zone-exit transition itself (an unintended setpoint
jump); (c) something else entirely. This needs targeted instrumentation
to determine whether the jump is in the *commanded* setpoint or the
*estimated* position before a fix can be designed.

Fix:
Not yet implemented. Deliberately scoped out of the BUG-013/014/015 fix
series rather than chased immediately, since it is a different
subsystem (GPS-denied zone-exit / EKF interaction) with a different
root cause than the sensor-only-bypass avoidance logic those bugs were
about.
