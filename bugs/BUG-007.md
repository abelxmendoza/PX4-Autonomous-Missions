BUG-007

Scenario:
Writing a new unit test to close a coverage gap flagged by an
algorithmic-audit review: no existing test exercised
`detect_obstacle`'s segment-vs-AABB geometry with a genuine off-corridor
hit (the existing left/right tests all happened to take the
near-start/center-bearing fallback path instead, never reaching the
general-case geometry).

Requirement violated:
No formal REQ-ID directly on this pure-geometry function, but this is
exactly the kind of defect REQ-CLEARANCE-01 (no mapped-obstacle
intersection) and REQ-AVOID-SENSOR-01 rely on `detect_obstacle` getting
right underneath them.

Symptom:
While building the new test (a flight path running parallel to an
obstacle, staying a full metre clear of it the entire time),
`segment_hits_expanded_aabb` reported a hit — a false positive — for a
path that never came within its own detection margin of the obstacle.

Expected behavior:
A segment that runs parallel to an obstacle's edge and stays outside
its expanded bounding box the whole time must not register as a hit.

Actual behavior:
It registered as a hit, which would have triggered unnecessary
avoidance maneuvers for paths that were never actually at risk.

Root cause:
In the Liang-Barsky slab-intersection loop, the case "segment is
parallel to this axis and lies entirely outside the slab" did `break`
with no `return`. Control fell through into the "segments overlap"
code below using whatever `t0`/`t1` values the *other* axis alone had
left behind, producing a result that had nothing to do with the axis
that actually ruled out a hit.

Fix:
Changed the parallel-and-outside case to `return False` immediately,
mirroring the sibling rejection path directly above it in the same
function.

Regression test added:
`test_mission_logic.py::test_segment_parallel_and_clear_of_obstacle_does_not_hit`
— the exact parallel, one-metre-clear case that surfaced the bug. Also
added `test_detect_obstacle_uses_real_segment_geometry_not_obstacle_center`,
confirming the segment-hit path uses the actual computed near-point
rather than the obstacle's center when a real hit does occur.
