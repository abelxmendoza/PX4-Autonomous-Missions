Autonomous Fleet Lab is evolving from a PX4/ROS 2 engineering project into a mission simulation and verification tool for robotics engineers. The goal: configure a fleet, test environmental and failure scenarios, replay behavior, and produce requirement-linked evidence. Today you can inspect recorded SITL missions and verification results; configurable fleet sizes, terrain/altitude scenarios, and synthetic traffic are on the roadmap—not yet available in this web app.

Existing engineering evidence

Cloud seeding A PX4 SITL sortie releases 0.080 kg only after altitude, weather, airspace, traffic, and communications allow it, then precision-lands on marker 4 with 9.8 cm horizontal error. Open the sortie → SLAM & costmap 2-D LiDAR SLAM on real PX4/Gazebo scans: odometry drifts 14 m, the SLAM path stays within centimetres, and its map feeds a layered costmap and a cost-aware planner. Replay the map building → Search & find A downward-camera drone in PX4/Gazebo finds 8 of 8 ground targets and locates each to under a metre, using only PX4's own estimate. Watch it in 3D → Validation platform CI on every push, a requirement registry with evidence for each claim, fault injection, and a MAVLink codec checked byte-for-byte against the reference library. Read the test plan ↗

Scope: software-in-the-loop research and developer tooling. Not a certified flight controller, real-time detect-and-avoid system, or authorization for real-world operations. PX4 supplies the flight stack; this project develops mission coordination, observation and verification around it.
