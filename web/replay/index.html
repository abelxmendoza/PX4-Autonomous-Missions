A software-in-the-loop UAV platform built with ROS 2, PX4, Gazebo, MAVSDK and MAVLink for developing, fault-testing, replaying and verifying autonomous behavior. Abel implemented the mission logic, sensor integration, fault handling, telemetry and verification around PX4’s flight controller. Start with a 64-second recovery flight: a commanded landing, confirmed task reassignment, and an independently checked result.
